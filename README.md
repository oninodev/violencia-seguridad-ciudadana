# Violencia y seguridad ciudadana

Página educativa interactiva sobre el problema de violencia y seguridad ciudadana, del curso Cultura Política y Realidad Nacional.

## Sitio web

https://oninodev.github.io/violencia-seguridad-ciudadana/

## Contenido

- `index.html`: versión proporcionada por el usuario en `01_violencia_seguridad_ciudadana (1).html`, conservada sin cambios.

## Publicación

GitHub Pages desde la rama `main`, carpeta raíz (`/`).
